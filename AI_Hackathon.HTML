The Challenge & The Solution

Domain Mismatch = Broken Attribution

When MQL leads arrive in Salesforce, the email domain often doesn't match a parent or subsidiary account record — preventing Traction from auto-assigning the lead.

❌
No account associationLeads — especially those with personal emails — go unlinked to CRM accounts, breaking pipeline attribution.
📉
Lost pipeline visibilityReps can't see account attendance, event influence, or follow-up history without the link.
✋
Manual cleanup requiredRevOps and admins spend cycles identifying and fixing orphaned records each week.

A Two-Layer AI Matching Agent

The agent resolves mismatches using programmatic fuzzy logic plus live web research:

🔍
Layer 1 — Fuzzy MatchingScores lead company name + domain against all account records using weighted logic with hierarchy-aware prioritization (subsidiaries vs. ultimate parents).
🌐
Layer 2 — Web ResearchWhen fuzzy scores are inconclusive, the agent searches Wikipedia, LinkedIn, and company sites to resolve ambiguity and confirm the correct account.
🎯
Confidence Score OutputReturns a final confidence-scored recommendation — reviewable by humans or auto-applied above a set threshold.

Use Case #2: Solved Without AI

Not every problem needs an agent. For non-MQL demo requests, updating the existing Traction flow was the right call:

⚡
Traction Flow UpdateWhen a demo request doesn't meet MQL criteria, Traction now silently assigns the lead/contact to the correct account — no AE notification spam.
💡
Right tool, right problemAutomation beats AI when logic is deterministic. AI is reserved for ambiguous, research-heavy matching that can't be scripted.

Case Studies — Real Matches Made

Click any case to expand the agent's reasoning.

🏢 Gap Inc. vs. Get Group — Ambiguous Domain TieWeb Research Tiebreaker
The fuzzy matching script scored Gap Inc. and Get Group nearly identically — the domain and company name signals were too close to call. The agent escalated to web research, found the lead's LinkedIn confirming employment at Gap Inc., then cross-referenced Gap's Wikipedia entry and official site to confirm. Final match: Gap Inc. ✓ at 96% confidence.
📧 CHRO with Personal Gmail — Uplift AttendeeMatched via Web Research
A C-suite executive registered for Uplift using their personal Gmail — common among senior leaders building personal brands. Domain fuzzy matching returned no CRM match. The agent used the name + company field to search LinkedIn and public bios, identified the correct employer, and linked to the parent account. Pipeline now attributed correctly.
🏛️ Government Agency — DOGE-Era Personal EmailMatched via Name + Org Research
During a period when many government employees registered with personal emails due to workplace policy concerns, domain matching was useless. The agent used web research to identify the agency from name and context signals — resolving the account match without any human intervention.

Roadmap — From Hackathon to Production
▶ Phase 1 — Now

Weekly Batch Review

  • Agent runs weekly on prior 7 days of unmatched leads
  • Outputs CSV with recommendations + confidence scores
  • GTM Systems QC review to validate and tune logic
  • Iterate on scoring weights and thresholds in parallel
⏭ Phase 2 — Next

Real-Time Integration

  • API callout from Traction flow on domain mismatch
  • Agent executes synchronously at lead creation
  • Auto-assign to account if confidence ≥ threshold
  • Notify account owner on high-confidence matches
🔭 Phase 3 — Future

Autonomous Continuous Matching

  • Always-on agent monitors all new leads in real time
  • Self-improving scores via outcome feedback loop
  • Extend to contact records and event registrants
  • Uplift-specific pipeline for CHROs & VP+ attendees
